# Day vs Night Classifier (Streamlit)

Aplikasi klasifikasi gambar siang/malam (HOG + Neural Network) menggunakan Streamlit.

## File

- `streamlit_app.py` - aplikasi Streamlit
- `requirements.txt` - dependencies
- `day_night_model.h5` - model hasil training
- `scaler.pkl` - StandardScaler hasil training

## Deploy ke Streamlit Community Cloud

1. Buka https://share.streamlit.io dan login dengan GitHub.
2. Klik **Create app** / **New app**.
3. Pilih repository `vanesamrd/ML_ganjil`, branch `main`.
4. **Main file path:** `streamlit-app/streamlit_app.py`
5. Klik **Deploy**.

Streamlit Cloud gratis dan tidak memerlukan kartu kredit.
